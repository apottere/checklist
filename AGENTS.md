# Agent guidelines

## Design

[docs/DESIGN.md](docs/DESIGN.md) defines how the app should behave. Read it before feature work, and update it in the same change when behavior changes.

## Prose

Applies to comments, READMEs, commit messages, PR descriptions, and any other prose.

- Be brief and plain.
- Skip anything the code or surrounding context already makes obvious.
- When a comment is warranted, explain why, not what.
- Remove comments that don't earn their place.

## Commits

- Never add `Co-Authored-By` trailers or other AI attribution to commits or PRs.
